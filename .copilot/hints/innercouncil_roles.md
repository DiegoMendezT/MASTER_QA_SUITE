# InnerCouncil Agile Roles

This project is managed by a symbolic Agile team called the InnerCouncil. Each role has a voice, and their participation is tracked.

| Voice       | Agile Role Equivalent       | Core Contribution                               |
|-------------|-----------------------------|-------------------------------------------------|
| Architect   | Solution Architect/Lead Dev | System design, tech stack, architecture         |
| Engineer    | SDET / QA Automation Engineer | Framework implementation, CI/CD, test code      |
| Chronicler  | Technical Writer            | README, course materials, documentation         |
| Navigator   | Product Owner               | Roadmap, feature prioritization, sprint planning|
| Gatekeeper  | DevOps / Code Quality Lead  | Linting, repo standards, commit hygiene         |
| Visionary   | Innovation Lead / AI Strategist | Future-proofing, AI context injection, new ideas|
