# JIRA-005: UX Bug - Multiple Test Execution Entry Points

**Summary:**
There are multiple pages/sections in the UI where tests can be run, causing confusion for users.

**Steps to Reproduce:**
1. Open the Streamlit UI.
2. Observe that tests can be executed from more than one place.

**Expected Result:**
There should be only one clear entry point for running tests.

**Actual Result:**
Multiple test execution buttons/pages are visible.
